# LyraTune
▎ Lyra Tune is a real-time automatic vocal tuner focused on low latency and natural sound.
▎
▎ - Fast, honest latency: 3.6 / 5.3 / 7.4 ms added latency (High / Mid / Low range at 48 kHz). It's reported to the host for delay compensation.
▎ - Accurate tracking: a YIN-based pitch detector with octave-error protection.
▎ - Speed and Amount: from natural, transparent correction to a hard-tuned effect, including an aggressive mode down to -3 ms.
▎ - Scales: chromatic, major, minor or fully custom. Click keys to allow or forbid notes; right-click to set the root.
▎ - Live visuals: an animated pitch orb, Input/Output HeatMaps and detected-note display, all driven by real DSP data.
▎ - Workflow: undo/redo, A/B snapshots, reset all, resizable UI (75–150%), tooltips.
▎ - Real-time safe: no allocations or locks on the audio thread, verified by automated tests.
